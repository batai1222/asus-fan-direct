# 2026.09.22.3 三档实测记录

日期：2026-09-22。机型：ASUS ProArt Studiobook H7600ZW。

本页整理自三档控制器的本机交付验收。发布打包阶段只做模拟检查和文件校验，没有重新执行硬件调速测试。

## 档位与持续控制

| 项目 | 实测结果 |
| --- | --- |
| 7000 档 | 连续 299.72 秒；排除前 30 秒升速后，495 个样本 CPU 全部为 6900–7000 RPM，GPU 为 6200–6300 RPM |
| GPU 限制 | 稳定段 57% 样本为 6300，其余为 6200；没有实现 GPU 7000，也没有达到逐样本最低 6300 |
| 6300 档 | 连续 59.78 秒；后 30 秒 CPU 6200–6400，GPU 6200–6300；结束时双扇均为 6300 |
| 7000 → 安静 | 30 秒附近 CPU 2900、GPU 4300；双扇 ≤3000 用时 49.81 秒，≤2500 用时 65.17 秒 |
| 6300 → 安静 | 双扇 ≤3000 用时 50.25 秒，≤2500 用时 64.54 秒 |
| 控制异常 | 最终四段实测均无错误；全速保持段未因 GPU 未到 7000 反复切普通／性能档 |
| 安静约束 | 安静请求未发送整机性能模式 2，也未发送原生强制全速命令 |

测试只覆盖有限时长、当前设备与当时负载，读数分辨率为 100 RPM。上述数据不构成无限期或其他机型保证。

## 安静降速对照

各轮从约 CPU 6900–7000、GPU 6200–6300 RPM 开始。第 35 秒附近结果：

| 方案 | CPU RPM | GPU RPM |
| --- | ---: | ---: |
| 直接安静＋AUTO | 2900 | 4400 |
| 每两秒重申安静＋AUTO | 2900 | 4400 |
| 先 AUTO 再安静 | 3100 | 4400 |
| 普通档 100 ms 复位后安静 | 2900 | 3900 |
| 最终程序复测同一复位方案 | 2500 | 3900 |

采用普通档短复位，是因为两次观察均有改善。各轮温度、负载和起始转速可能略有差异，不能据此宣称瞬间静音。

安静流程依次释放双扇强制状态、短暂进入普通模式 0（100 ms）、进入安静模式 1、再次确认 AUTO。不会经过高速／性能模式 2。

## 已知接口限制

本机额外的静音策略端点 `0x00110018`、`0x00120075` 和温度端点 `0x00110011` 返回不支持，没有向这些端点写入未知值。原生 GPU 全速命令返回成功，但未带来 7000 RPM；程序保留尽力提升并展示真实读数。
